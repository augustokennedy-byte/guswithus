# Resource Center toolchain

`resources.json` is the source of truth for The GUS Resource Center. The seven
HTML pages under `/resources/` are built from it. Edit the JSON, run the build,
never hand-edit the HTML.

## The three scripts

| Script | What it does |
|---|---|
| `check_links.py` | Opens every outbound link and reports anything that is not a 200. Run this first. |
| `build.py` | Writes `resources.json` into all seven pages and stamps the "last checked" date. |
| `extract.py` | Reads the HTML back into `resources.json`. Only needed if the JSON is ever lost. |

```bash
cd "<repo root>"
python3 _tools/check_links.py _tools/resources.json
python3 _tools/build.py . _tools/resources.json
```

Python 3.9, standard library only. Nothing to install.

## What build.py touches

Only the `<main>` block of each page, plus the one `<p class="checked">` line in
the footer. The head, CSS, navigation, search script and the rest of the footer
are hand-tuned and are left alone. Running the build twice in a row produces no
change, so it is always safe to re-run.

The seven pages are `resources/index.html` (every card) and one page per borough,
each filtered on the card's `boro` list.

## Card fields

```jsonc
{
  "cat":      "food",                  // must match a section's cat
  "urgent":   false,                   // true adds the red "urgent" styling
  "boro":     ["jamaica", "queens"],   // jamaica queens brooklyn manhattan bronx statenisland
  "badge":    "Right here in Jamaica", // optional
  "name":     "The River Fund New York",
  "what":     "One of the biggest pantries in Queens...",
  "addr":     "89-11 Lefferts Blvd, Richmond Hill, NY 11418",  // optional
  "note":     "Wednesdays serve seniors...",                   // optional
  "acts":     [ {"kind":"go",  "href":"https://...", "label":"See pantry days", "external": true},
                {"kind":"tel", "href":"tel:+17184411125", "label":"(718) 441-1125", "external": false} ],
  "keywords": " food hungry hunger groceries eat feed my family pantry "
}
```

Every card needs exactly one `go` action. A `tel` action is optional. Set
`external` to true for any link that leaves guswithus.org.

`keywords` is the tail of the search index a reader's typing is matched against.
The rest of the index (name, description, note, address, section, boroughs) is
regenerated by `build.py` on every run, so changing a description keeps search
working automatically. Put words a person would actually type in `keywords`,
including misspellings and plain-language phrases.

## Rules for what goes on the page

- Every link goes to the **actual application**, not an agency homepage.
- Assume the reader is on a public computer at a library: no login, nothing
  saved, tap-to-call numbers.
- Jamaica first, then Queens, then Brooklyn, Manhattan, Bronx, Staten Island.
- Verify with a real browser before trusting a failure. Several of these sites
  block automated requests and look broken when they are fine. The known ones
  are listed in `BOT_BLOCKED` in `check_links.py`.
